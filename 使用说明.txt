杯杯倒满 Mod 加载器 1.1.4
适配游戏 1.0.2.0 / Windows 64 位

首次安装
1. 从 https://github.com/chenkkano-sketch/feed-the-cups-mod-loader/releases/latest 下载 FTCModLoader-1.1.4.zip，完整解压到任意文件夹。
2. 双击“杯杯倒满Mod加载器.exe”。启动器会查找 Steam 游戏目录；如有多个位置，选择 Feed the Cups.exe 所在目录。
3. 点击“安装 / 更新”。安装完成后，启动器会打开游戏目录中的正式入口。
不需要运行 .cmd、PowerShell 脚本，也不要单独复制 Mod 文件到游戏资源包中。

日常使用和更新
在游戏目录双击“杯杯倒满Mod加载器.exe”，选择配置或勾选模块，点击“启动游戏”。
启动器右侧可检查 GitHub 更新、下载并升级，也能打开 GitHub 或选择本地完整 ZIP 升级。更新前请退出游戏。
GitHub 下载会核对 SHA-256；若更新失败，原 ZIP 会保留。只更新内置 Mod 时，使用启动器底部的“更新内置 Mod”。
更新只安装版本更高的内置模块，保留已有配置和第三方模块；被替换的旧模块保存在 FTCModLoader/Backups。相同版本不覆盖，避免旧包倒灌。
手动安装第三方 .ftcmod 可使用“导入 Mod…”或拖放文件到启动器；导入失败时会恢复旧模块。
游戏正在运行时请先正常保存退出，再更新或切换配置。正常游戏存档不由启动器复制或覆盖。

联机房租
所有参与者安装同版完整包，在启动器选择“房租联机＋实时搬运（测试）”，再点击“启动游戏”。
房租模式与正常模式使用同一账号存档，房租经营另存记录；房主保存共同经营，成员领取个人奖励。
最终绿钞以本局最高杯币除以 20 向下取整，并受开局绿钞上限限制。

目录
FTCModLoader/Mods：已安装模块；Packages：可安装的内置包；Profiles：启用配置；Backups：更新备份；Logs：日志；Core：兼容层；SDK：开发文档。
启动器会在 Cache 中生成运行包，不修改原版 Feed the Cups.exe 和 Feed the Cups.pck。
