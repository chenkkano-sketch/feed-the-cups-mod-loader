# 人才市场 1.5.3

兼容房租模式 0.11.0 的租金压力调整：房租模式工资仍按原来的工资基准曲线增长，提高店铺租金不会额外放大员工工资；已开店锁定的工资保持原额。

修复垃圾袋反复取出再投入室内桶：室内／户外垃圾桶按原版分类识别，垃圾袋仅可运至容量足够且可达的户外桶，无法运出时不提前取袋。修正靠墙柜台的交互检查，取放动作只检查到设备可操作边缘，行走仍检查员工宽度与关闭的门。补杯无法执行时显示缺少杯组、尚未开箱、操作位置不可达或资源被占用的具体原因。

全部21个现存技能已开放，包括清洁、协作光环、团队核心和笨手笨脚。新增七个速度被动、两个工作速度减益，彼此可并存叠加；同名技能仍不可重复。手脚麻利、熟能生巧、健步如飞、疾行已移除，旧配置中的对应技能槽读档时清为空槽，合同工资保留。基础冲煮、高级冲煮、制作饮料仍保持删除。

按 F3 打开人才市场，勾选「调试模式」，切换「已聘店员」并点击卡片上的「调试技能 / 星级」。可自由编辑四个技能槽和1～6星，应用后即时保存；营业中也可修改。重复技能不可选，同系高级技能自动替换低级技能。所有现存技能均可配置并生效。应用时先安全中断任务并将手持物品放到地面，合同工资、已记工资、身份、外观和位置保留。中断的垃圾袋可由倒垃圾技能接着清运。

在 Mod 加载器中勾选「人才市场」后启动游戏。支持单机正式关卡，也可与「房租模式 0.8.2」「自由搬运」一起使用。进入店铺后按 **F3** 打开市场；再次按 F3 或 Esc 返回店铺。

## 招聘、刷新与合同

- 所有人才统一为**店员**，根据已拥有的主动技能自动安排工作；界面不再划分岗位或显示旧能力面板。
- 每天提供 **5 位候选人**。同一天反复打开市场保留原名单；付费刷新才会更换未聘用候选人。
- 当天刷新价格依次为 **100、200、400、800……元**，每次翻倍，最高封顶 10 亿元。费用即时扣除，不会在晚间重复收取；次日刷新次数归零、价格恢复 100 元。保存和读档保留当日次数。
- 最多聘用 **4 人**，安排休息的员工也占在职名额。招聘前现金需至少够支付该员工当天日薪；工资在开店后计入当天结算。
- 开店前可招聘、刷新、安排休息或解雇；休息员工不出勤、不计当天工资。**开店时锁定当天出勤名单和整日日薪**，营业期间可查看员工，但不能通过解除合同或休息免除工资。
- 合同基薪按星级及技能定价并保留。房租模式的当日日薪为「基薪 × 原工资基准曲线当天值 ÷ 首日值」，房租 0.11.0 提高店铺租金时不额外放大工资；正式关卡为「基薪 × [1＋0.5×（天数－1）]」，均向上取整；每天从基薪计算，不按昨日工资复利。免租或租金折扣不降低工资。开店时锁定该班次每人的日薪，收店计入原生「今日支出」，同一天只扣一次；原游戏免工资事件照常生效。
- 准备期遣散须即时支付该员工当天一整天日薪作为离职金，随天数上涨；现金不足时保留合同和现金。离职金计入今日员工支出，日终不会重复扣除，营业期间不能遣散。
- 人才卡展示真实角色模型、原生皮肤和兼容衣装；聘用后及读档保持同一形象，不重新随机。
- 旧版在职员工自动迁移为统一店员，原职责转为相应主动技能，保留员工 ID、姓名、合同基薪、出勤、形象及存档库存。原顺序前 4 人现役，其余完整保存在归档中，不自动补位、不占名额、不生成员工或计入新一天工资，归档本身不收离职金；当天已经开店锁定的工资仍保持原额。新开一局仍需重新招聘。

## 星级与四个技能槽

每人有四个技能槽，每槽独立决定档次：**50% 空槽、45% 普通技能、5% 高级技能**。在对应档次的池中选择尚未拥有的技能，同一员工不会出现相同技能；同系高级技能替换低级技能，两者不能共存。旧候选、在职和归档员工读档时清理重复项及被高级替换的低级项；合同工资及其他数据保留。

| 星级 | 概率 | 颜色 | 动作耗时倍率 |
| --- | --- | --- | --- |
| 1 星 | 75% | 白 | 2.5 |
| 2 星 | 20% | 蓝 | 2 |
| 3 星 | 3% | 粉 | 1.75 |
| 4 星 | 1% | 紫 | 1.5 |
| 5 星 | 0.8% | 金 | 1.25 |
| 6 星 | 0.2% | 彩 | 0.5 |

实际动作耗时 = 原生动作耗时 × 星级倍率 × 自身被动倍率 × 附近最强协作光环倍率。原生基础动作是 1 秒时，六星为 0.5 秒、一星为 2.5 秒；六星的动作速度为基准的2倍。移动速度由移动被动决定，星级不会额外加快走路。

## 主动技能

| 技能 | 可以完成的工作 |
| --- | --- |
| 点单 | 营业后走到点单机前，为排队顾客接单。 |
| 高级点单 | 包含普通点单；还会走到堂食桌前，为桌边等候顾客点单。点单机和堂食桌交替处理；目标需可达，顾客离开或已被其他人服务时释放任务并重新安排。 |
| 补充空杯 | 杯架某尺寸剩余不超过 4 个时，从现有库存搬一组对应杯组补入，每组 10 个；不会挪用订单杯。 |
| 清洁 | 拿取拖把，清洁垃圾与污渍，并洗净归位。 |
| 设备维修 | 优先维修跳闸电箱恢复供电，再走到故障设备旁，按原生维修进度修复。 |
| 货架整理 | 从已经开封的物料箱中逐件取货上架；直接识别货架旁地上的开箱包裹，无需把箱子放上柜台。 |
| 高级货架整理 | 包含普通货架整理；把包裹搬到货架旁可用的室内地面后开箱、逐件上架，不占用柜台。空地被占用时重新安排；没有可用空地时也可直接打开可达的现有包裹。 |
| 丢垃圾 | 室内垃圾桶达到 50% 容量后，打包并运至户外垃圾桶。 |
| 高级丢垃圾 | 包含普通丢垃圾；无其他可执行任务时，也清运不足50%的非空垃圾桶。还会回收耗尽的果汁瓶、原料罐等一次性废包装，将真正取空的物料箱拆平并抱到可用垃圾桶投入。 |

运输包裹开箱需要「高级货架整理」。仅有补充空杯技能时，从货架、已开封箱或地面现有杯组取货，不自行打开密封运输箱。

## 被动技能与被动减益

| 技能 | 实际效果 |
| --- | --- |
| 社畜 | 工作速度 +30%，普通被动。 |
| 工匠精神 | 工作速度 +50%，高级被动。 |
| 认真 | 工作速度 +15%，普通被动。 |
| 工作狂 | 工作速度 +50%，高级被动，可与工匠精神并存。 |
| 神速 | 移动速度 +30%，高级被动。 |
| 运动健将 | 移动速度 +20%，普通被动。 |
| 灵活 | 移动速度 +10%，普通被动。 |
| 偷懒成瘾 | 工作速度 -30%，普通减益。 |
| 慢性子 | 工作速度 -15%，普通减益，可与偷懒成瘾并存。 |
| 协作光环 | 180 像素内其他店员动作耗时减少 8%。 |
| 团队核心 | 高级被动，240 像素内其他店员动作耗时减少 15%，覆盖协作光环。 |
| 笨手笨脚 | 被动减益，自身动作耗时增加 30%，移动速度降低 10%。 |

新的工作速度百分比相加后换算耗时：耗时倍率 = 1 ÷（1 + 工作速度加成总和）。工匠精神与工作狂合计 +100%，工作速度变为2倍、动作耗时减半；四个工作加速被动合计 +145%，速度变为2.45倍。偷懒成瘾与慢性子合计 -45%，剩55%工作速度；社畜 +30% 与偷懒成瘾 -30% 相抵。三种移动被动合计 +60%，走路速度变为1.6倍。工作与移动两类独立计算，再应用星级、光环及笨手笨脚原有的耗时／移动倍率。

这些新被动和减益互不替换，仍占用每人四个技能槽；需要拥有相应主动技能才能执行工作。新被动加入对应普通／高级抽取池，减益加入普通池。清洁、光环及笨手笨脚均已解除暂停。

同类光环取附近最强效果，不按人数叠加；离开范围、休息或停止工作后不再为同事提供光环。被动与被动减益不会单独赋予点单、补杯或整理等工作能力。

## 店铺准备与当前边界

- 员工会实际行走、搬运并消耗库存，不会凭空补货或自动购买设备、原料。
- 保留设备周围通路。原料不足、位置已满、机器不可用或目标无法到达时，员工会等待或重新安排任务；可查看头顶状态和动作进度。大型设备木箱组装、购买与摆放仍由玩家负责。
- 高级丢垃圾只拆真正空箱。箱内还有货物时不会误拆或丢掉物资；拆平后实际投入垃圾桶，遵守垃圾容量限制。耗尽包装按真实剩余原料判断，正常杯组、空茶壶和出料壶会保留。
- 点单在营业后进行；具备整理、补杯、维修等技能的店员也能在开店前工作。搭配「自由搬运」时，F2 搬运暂停员工，退出后恢复；无限准备由该模块提供。
- 保存、读档、结算、休息和解雇时，会安全归还或放下正在处理的物品。合同、候选、刷新次数与计薪状态随本局保存；继续时请保留原来的 Mod 组合。

搭配房租模式 0.8.2 时，先进入游戏里的家，再按 F4 或点「房租模式」创建／继续经营。角色、皮肤、穿戴和家居加成沿用当前存档原生规则，每日基础礼物及原生额外礼物都保留。房租使用独立存档组，不自动同步或覆盖原版家居存档。

## 模块结构

- `Skills/SkillCatalog.gd`：技能名称、类别、抽取池、能力权限与被动数值。
- `TalentRules.gd`：六星概率、四槽生成、合同基薪、每日候选、刷新价格和 schema 2 存档迁移／超额归档。
- `AI/SkillScheduler.gd`：按员工技能选择工作，同一员工一次执行一条任务。
- `Actors/`：真实 NPC、寻路、动作计时、被动与附近光环。
- `Roles/` 与 `Helpers/`：复用原生设备、库存和交互的工作流程及资源锁。
- `UI/TalentMarketPanel.gd` 与 `Visuals/PortraitFactory.gd`：市场面板、人才卡和真实角色形象预览。
- `TalentMarket.gd`：招聘、出勤、刷新、每日工资倍率、离职金及原生存档／结算集成。

当前版本面向单机；饮料制作与冲煮由玩家完成。

## 关闭大门与员工寻路

员工按真实碰撞形状、碰撞掩码及身体宽度检查通路，包括原版碰撞层为0但仍挡人的店门。开业前大门关着时，有可通行路线则绕行；没有路线的户外任务暂不领取。门在员工走路途中关闭时立即检查并重算路线，无路则停止并释放任务锁，再安排其他可达工作；手中真实物品继续保留供后续接手。门打开后重新检查并恢复可达任务。操作位置也检查是否隔着关闭的大门，避免站在门内尝试拿取门外的包裹。顾客原生寻路图保持原有规则。
